# Как запустить дашборд на iPhone — пошаговый гайд

## Что тебе понадобится

- [Node.js](https://nodejs.org) — среда выполнения JavaScript
- [Git](https://git-scm.com) — система контроля версий
- [GitHub аккаунт](https://github.com) — бесплатный, для хранения кода
- [Vercel аккаунт](https://vercel.com) — бесплатный хостинг для Next.js
- [API ключ Anthropic](https://console.anthropic.com) — для сканирования чеков (~$0.004 за чек)

---

## Шаг 1 — Установи Node.js

### Mac
1. Открой браузер, зайди на https://nodejs.org
2. Нажми большую зелёную кнопку **"LTS"** (не Current)
3. Скачается файл `.pkg` — открой его, следуй инструкциям установщика
4. Проверь установку: открой **Терминал** (Cmd+Space → "Терминал") и введи:
   ```
   node --version
   ```
   Должно показать что-то вроде `v22.0.0`

### Windows
1. Открой браузер, зайди на https://nodejs.org
2. Нажми кнопку **"LTS"**
3. Скачается файл `.msi` — открой его, жми "Next" на каждом шаге
4. Проверь установку: открой **PowerShell** (Win+X → "PowerShell") и введи:
   ```
   node --version
   ```
   Должно показать что-то вроде `v22.0.0`

---

## Шаг 2 — Запусти локально

Открой терминал в папке с проектом и выполни по очереди:

```bash
npm install
```
Это загрузит все зависимости (примерно 1-2 минуты).

```bash
npm run dev
```

Открой браузер и зайди на адрес: **http://localhost:3000**

Ты должен увидеть дашборд с тёмным фоном и тремя вкладками: Финансы / Цели / Привычки.

Чтобы остановить сервер — нажми `Ctrl+C` в терминале.

---

## Шаг 3 — Получи API ключ Anthropic (для сканирования чеков)

1. Зайди на https://console.anthropic.com
2. Зарегистрируйся или войди в аккаунт
3. В левом меню нажми **"API Keys"**
4. Нажми кнопку **"Create Key"**
5. Введи любое название, например `dashboard`
6. Скопируй ключ — он выглядит как `sk-ant-api03-...`
7. **Сразу сохрани ключ** — после закрытия окна он больше не покажется!

Создай файл `.env.local` в папке проекта:
```
ANTHROPIC_API_KEY=sk-ant-api03-твой_ключ_здесь
```

**Стоимость:** ~$0.004 за одно сканирование чека. При 100 чеках в месяц — около $0.40.

## Шаг 4 — Залей на GitHub

### Создай репозиторий
1. Зайди на https://github.com
2. Нажми зелёную кнопку **"New"** (или "+" в правом верхнем углу → "New repository")
3. Назови репозиторий, например `my-dashboard`
4. Выбери **"Private"** (чтобы твои данные не были публичными)
5. Нажми **"Create repository"**

### Инициализируй и залей код
В терминале в папке проекта:

```bash
git init
git add .
git commit -m "Initial dashboard"
git branch -M main
git remote add origin https://github.com/ТВОЙ_USERNAME/my-dashboard.git
git push -u origin main
```

Замени `ТВОЙ_USERNAME` на своё имя пользователя GitHub.

GitHub попросит логин и пароль — используй **Personal Access Token** вместо пароля:
1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Generate new token → выбери `repo` → Generate
3. Скопируй токен и используй его как пароль

---

## Шаг 5 — Деплой на Vercel

1. Зайди на https://vercel.com и нажми **"Sign Up"**
2. Выбери **"Continue with GitHub"** — так Vercel получит доступ к твоим репозиториям
3. На главной странице нажми **"Add New..."** → **"Project"**
4. В списке репозиториев найди `my-dashboard` и нажми **"Import"**
5. В разделе **"Environment Variables"** добавь переменную:
   - **Name:** `ANTHROPIC_API_KEY`
   - **Value:** вставь свой ключ `sk-ant-api03-...`
6. Нажми **"Deploy"**

Vercel задеплоит проект за 1-2 минуты. После этого покажет адрес вида `my-dashboard.vercel.app`.

---

## Шаг 6 — Добавь на домашний экран iPhone

1. Открой **Safari** на iPhone (именно Safari, не Chrome или другой браузер!)
2. Перейди по адресу твоего дашборда, например `my-dashboard.vercel.app`
3. Нажми кнопку **поделиться** — это квадрат со стрелкой вверх внизу экрана
4. Прокрути список вниз и выбери **"На экран Домой"**
5. Введи название (например "Дашборд") и нажми **"Добавить"**

Теперь на домашнем экране появится иконка дашборда. При открытии через неё:
- Нет адресной строки браузера — как настоящее приложение
- Работает в полноэкранном режиме
- Сохраняет все данные локально на телефоне

---

## Как обновить после изменений

Если ты что-то изменил в коде локально:

```bash
git add .
git commit -m "update"
git push
```

Vercel автоматически заметит новый коммит в GitHub и передеплоит проект за 1-2 минуты. Твои данные в дашборде не потеряются — они хранятся в памяти телефона, не на сервере.

## Частые проблемы и решения

### 1. `npm install` зависает или падает с ошибкой
**Ошибка:** `EACCES: permission denied`

**Решение (Mac):** Не запускай с `sudo`. Установи nvm:
```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

### 2. `npm run dev` — ошибка "Port 3000 is already in use"
**Ошибка:** `Error: listen EADDRINUSE: address already in use :::3000`

**Решение:** Используй другой порт:
```bash
npm run dev -- -p 3001
```
Затем открывай `http://localhost:3001`

### 3. Сканирование чека не работает
**Ошибка:** "Не удалось распознать чек"

**Причины и решения:**
- Файл `.env.local` не создан или ключ введён неправильно — проверь файл
- На Vercel не добавлена переменная `ANTHROPIC_API_KEY` — зайди в настройки проекта на vercel.com → Settings → Environment Variables
- На аккаунте Anthropic нет баланса — зайди на console.anthropic.com и пополни

### 4. Данные пропадают при обновлении страницы
Данные должны сохраняться в localStorage браузера. Если не сохраняются:
- Убедись, что в Safari не включён режим "Частный доступ" (Private Browsing)
- Не очищай данные сайта в настройках Safari

### 5. Кнопка камеры не работает
На iPhone сканирование чека открывает камеру автоматически. Если не открывается:
- Safari спросит разрешение на доступ к камере — нажми "Разрешить"
- Если отказал ранее: Настройки → Safari → Камера → Разрешить

### 6. "Дашборд" не появляется на экране как приложение (без адресной строки)
- Используй только **Safari** для добавления на экран Домой (Chrome не поддерживает PWA на iPhone)
- После добавления обязательно открывай через иконку на домашнем экране, а не через браузер
